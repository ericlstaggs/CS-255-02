## C++ Learning Repository
Welcome to my C++ Learning Repository! This repository serves as a personal sandbox and tracking space for mastering modern C++ concepts.
The projects included range from foundational logic to advanced object-oriented programming (OOP). Inside, you will find a mix of experimental code and complete, fully functional tools.
## 🚀 Project Status

* In Progress: Some directories contain experimental code, syntax tests, and active drafts.
* Done & Working: Several core projects are completely finished, compiled, and thoroughly tested.

------------------------------
## 📂 Featured Projects## 🔢 1. Fractions Calculator

* Status: Done
* Concepts Covered: Fractional arithmetic, greatest common divisor (GCD) algorithms, and struct/class structures.
* Description: A program designed to handle fraction operations (addition, subtraction, multiplication, and division) without losing precision by avoiding standard floating-point numbers.

## 🔄 2. Operator Overloading Practice

* Status: Done
* Concepts Covered: Compile-time polymorphism, operator+, operator-, and stream insertion/extraction (<< and >>).
* Description: A dedicated module exploring how to extend standard C++ operators. It allows custom classes to behave intuitively, much like native primitive data types.

## 🎭 3. Type Casting Sandbox

* Status: Done
* Concepts Covered: static_cast, dynamic_cast, reinterpret_cast, and const_cast.
* Description: A collection of short scripts demonstrating the explicit conversion of data types. It highlights the safety differences and structural boundaries between standard C-style casts and robust C++ casts.

## 💰 4. The Money Class

* Status: Done
* Concepts Covered: Data encapsulation, fixed-point math emulation, and input validation.
* Description: A robust class built to manage financial values accurately. It explicitly avoids floating-point rounding errors by handling dollars and cents as distinct integrated integers.

## 🏦 5. Fixed-Array Bank Account Tracker

* Status: Done
* Concepts Covered: Fixed-size arrays (std::array / native arrays), pointer arithmetic, structures, and basic database boundaries.
* Description: A lightweight banking application that stores, updates, and tracks a specific, limited number of user accounts within a rigid memory footprint.

------------------------------
## 🛠️ Getting Started## Prerequisites
To compile and run these projects, you need a standard C++ compiler supporting at least C++17 or higher:

* GCC / G++ (g++ --version)
* Clang (clang++ --version)
* MSVC (Visual Studio)

## Compilation Example
Navigate to any functional project directory and compile using your terminal:

g++ -std=c++17 main.cpp -o program
./program
